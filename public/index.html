Arc Token Pre-Flight

A pay-per-call API that inspects any token contract on Arc mainnet and returns the risk warnings an autonomous agent needs before it trades. No account, no API key. Payment is the authentication.

Try it — unpaid call returns the price list

curl -i "/api/kiem-tra?address=0x171A4217B86A807A64eB94757Db6849fb4bDbAA0"

Returns HTTP 402 Payment Required with a machine-readable accepts array. An x402 client reads it, signs an authorization, and retries. Open it in the browser →

What you get for 0.01 USDC

  • Contract type — ERC-20, ERC-721 or ERC-1155, detected via ERC-165
  • Name, symbol, decimals, total supply
  • Risk warnings for Arc-specific traps

The warnings are the point. Three real ones this catches:

cirBTC has 8 decimals Not 18. Any client that hard-codes 18 misreads every balance by a factor of 1010.
USDC on Arc is a precompile USDC is Arc's native gas currency, exposed through two interfaces that share one balance — native at 18 decimals, ERC-20 at 6. Mixing them is a 1012 error, and balanceOf() returning 0 does not mean the native balance is 0.
Address has no bytecode The contract exists on testnet but not on mainnet. The ERC-8004 registries are the live example of this.

How payment works

Protocolx402, scheme exact
SettlementCircle Facilitator Service
MechanismEIP-3009 TransferWithAuthorization — the buyer signs, no transaction of their own
Networkeip155:5042 (Arc mainnet)
AssetUSDC 0x3600…0000
Price0.01 USDC per call
FinalityInstant — Arc has deterministic finality, so there is no pending state to handle

Every successful response carries an X-PAYMENT-RESPONSE header and a transaction hash verifiable on explorer.arc.io. The report is produced only after settlement returns success: true.

Why this is Arc-native

It could not be built this way anywhere else. Arc's instant finality removes the pending-payment state machine. Circle pays the settlement gas, so a 0.01 USDC call is economically possible. And the warnings it returns are drawn from Arc's own EVM differences — the dual-interface USDC precompile above all.
